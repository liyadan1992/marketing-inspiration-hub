# 广告营销灵感库

一个可直接部署到 GitHub Pages 的静态网页。无需安装依赖或构建步骤。

## 本地预览

用浏览器打开 `index.html` 即可。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `marketing-inspiration-hub`。
2. 将本项目中的 `index.html` 和 `README.md` 上传到仓库根目录并提交。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，然后保存。
5. 等待 GitHub Pages 完成发布，按 Pages 页面显示的网址访问。

如果仓库是公开的，已发布网页通常也能被任何拿到网址的人打开；请勿将私人信息加入页面。

## 目前包含的功能

- 数英、梅花网和广告门的营销文章与案例列表
- 按来源、类型筛选，以及关键词搜索
- 已读标记与收藏
- 行业调研报告占位区
- 按日期记录每日工作内容、勾选清单和工作笔记

## 数据保存说明

这是纯静态网页。已读状态、收藏、每日清单和工作笔记保存在当前浏览器的本地存储中，不会随 GitHub 仓库同步，也不会自动跨设备共享。文章数据当前随 `index.html` 一起保存；更新文章需要修改并重新提交该文件。
