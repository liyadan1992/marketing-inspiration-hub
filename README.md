# 广告营销灵感库

一个单文件、无需后端的营销工作台。它展示来自数英、梅花网和广告门的文章与案例链接，并提供搜索、筛选、已读、收藏、每日工作记录和社群内容记录。

## 本地运行

直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。部署到任何支持静态文件的服务时，以 `index.html` 作为入口即可。

## 数据与隐私

- 灵感列表保存在 `index.html` 的 `feed-data` JSON 中；页面不会自行抓取来源网站。
- 已读、收藏、每日工作和社群内容仅写入当前浏览器的 `localStorage`，不会随源码提交，也不会跨设备同步。清除浏览器网站数据会清除这些记录。
- 灵感标题经过主题化整理。文章、案例及其可能展示的配图归原来源和权利人所有；本项目只提供来源链接，不转载原文。
- 公开部署时，`index.html` 中的灵感列表对所有访问者可见。请勿把私人工作记录或敏感信息写入源码或 `feed-data`。

## 更新灵感列表

编辑 `feed-data` 时，先打开原文核对标题、日期和直链，按 URL 与营销主题去重，再同步更新页面的总数和来源计数。按日期从新到旧排列，保持每条记录的 `id` 唯一。

本地另有每日更新任务；它不是网站的一部分。公开仓库和静态托管服务不会自动运行该任务。更新页面后，还需要把修改推送到仓库并由托管服务发布。

## 发布到 GitHub Pages

把本目录推送到公开 GitHub 仓库后，在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，发布分支选 `main`、目录选 `/(root)`。此后推送到 `main` 的网站文件会触发发布。首次发布完成后，以 Pages 设置页显示的网址为准。
